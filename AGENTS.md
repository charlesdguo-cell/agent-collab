# Agent Collab
Local-first Feishu collaboration. Each person binds their own computer and dedicated bot. Binding defines execution ownership, not communication partners. Never substitute a maintainer machine for a user installation.
Preserve task/session/thread bindings and credentials. Do not blindly replay uncertain execution. Use npm test. Distinguish simulated tests, real local integration, and real user acceptance. No user configs, secrets, conversations, or private project files belong in this repository.

Maintainer release handoff: after publishing an update, open a new topic in the authorized team collaboration group and mention every currently registered agent counterpart. Point to INSTALL.md with runtime resolution of the newest published release (including previews), never a pinned install version. Ask each counterpart to check its own installation, preserve configuration/tasks, update safely and report its actual version and self-check outcome in that topic. Record delivery separately from confirmed upgrades; never substitute the maintainer machine for another person's computer. Resolve group/recipient IDs from private authorized configuration, not this public repository.
