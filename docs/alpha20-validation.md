# alpha.20 — 富文本与图片上下文

## 修复

原实时入口仅接收 text；话题补取只读 content.text，post 消息因此被丢弃或投影为空。现将实时接收、历史补收及引用摘要统一到 messageContent。支持直接及语言包装的 post，保留标题、段落、链接、提及、代码块与图片资源来源；未知结构明确标记不完整。提及路由仍只信平台 mentions，不从富文本标签授予路由身份。

已有 Codex 会话收到引用消息时补取被引用消息，不只在首次建立会话时读取。图片按原消息 ID 和资源键从飞书资源接口读取，去重、有界下载，作为原生 image 输入交给 Codex。图片下载失败不丢正文，也不宣称已看图；不下载正文里的任意 URL。暂停、取消、去重及原会话绑定逻辑未改变。

## 验证与边界

- Node 回归覆盖富文本解析、历史投影、提及身份、图片去重/失败/限额/超时、已有会话引用补取及新建/恢复会话原生图片传递。
- Python 安装及维护升级回归通过。
- 维护者实际读取一条含两张图片的飞书 post，两张图片均从原消息下载成功；真实本机 Codex app-server 完成两张图片的视觉识别。测试仅要求描述界面类型，没有执行截图中的任务或向群发送测试答复。
- 使用本机安装的 Codex app-server schema 核对 image.url 输入字段。
- 不代表其他电脑已升级，也不代表任意模型/CLI 版本支持视觉；其他文件、音视频输入及自动产物发布不在本次验收范围。
- 私有消息、图片、资源键、会话及认证资料不进入仓库或发布包。
